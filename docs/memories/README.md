# Memories

This folder stores high-signal implementation notes that are easy to lose in terminal history.

Use these files for:
- architecture discoveries
- testing findings
- blockers and resolutions
- repo-specific gotchas
- follow-up work that should not be rediscovered from scratch

Suggested pattern:
- keep one file per topic or milestone
- prefer concise facts over long narrative
- update when a finding changes or a blocker is removed
